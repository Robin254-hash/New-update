# Alfayo Robin — Cybersecurity Portfolio

A Jekyll portfolio built with the Minimal Mistakes theme and published through GitHub Pages.

## Main pages
- Home: professional introduction and featured work
- Labs: HTB, TryHackMe, and hands-on learning notes
- Projects: selected projects and planned deliverables
- Wazuh + Metasploitable 3: home-lab investigation log
- Resume: web resume and PDF link
- Blog: learning notes

## Updating the portfolio
1. Edit Markdown pages in `_pages/` and `index.md`.
2. Add custom styles in `assets/css/main.scss`.
3. Add your own screenshots to `assets/images/lab/` and link them from the relevant page.
4. Replace the screenshot placeholders only with genuine evidence from your own lab.
5. Keep sensitive information out of screenshots: passwords, tokens, private keys, public IPs if inappropriate, and organizational data.
6. Keep project status labels accurate; do not claim an alert, detection, or test result unless you verified it.

## Local preview (optional)
Install Ruby and Bundler, then run `bundle install` and `bundle exec jekyll serve`. The theme is loaded from the Minimal Mistakes remote theme configuration.
